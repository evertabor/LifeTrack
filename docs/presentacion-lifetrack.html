LifeTrack 04 / 08

Cómo funciona

Del movimiento a una decisión informada.

1. Registra

Añades un ingreso o gasto con fecha, categoría, monto y descripción opcional. Validación inmediata: monto > 0, máx 2 decimales, fecha no futura.

2. Revisa

El dashboard muestra ingresos, gastos, balance del mes y desglose por categoría. Compara con el mes anterior para detectar tendencias.

3. Anticípate

Presupuestos con semáforo visual. Proyección: balance actual − gasto medio diario × días restantes. Alertas: gasto ≥ 2,5× la media de su categoría (mín. 5 movimientos).

LifeTrack 05 / 08

Cómo se construyó

Desarrollo dirigido por especificaciones con apoyo de IA.

01

Especificación como fuente de verdad

Todo parte de docs/01-especificacion.md: requisitos, reglas, historias, criterios de aceptación. Nada se implementa si no está ahí.

02

SDD + IA como copiloto

Exploración → Propuesta → Especificación delta → Diseño técnico → Tareas → Implementación → Verificación. La IA propone, yo decido y valido.

03

Reglas estrictas (AGENTS.md)

Clean Architecture verificada por tests, OWASP Top 10:2025, cero comentarios en código, vistas sin lógica, JavaScript en IIFE, dependencias hacia dentro.

04

Puertas de calidad automáticas

Build Release sin warnings · 255 tests (Domain, Application, Architecture, Integration) · dotnet format · análisis vulnerabilidades · CodeQL en CI.

Principio: La IA acelera la implementación; los requisitos, la seguridad, la arquitectura y la aceptación son decisiones humanas verificables.

LifeTrack 06 / 08

Arquitectura y seguridad

Capas claras. Datos protegidos por diseño.

Clean Architecture

Separación estricta de responsabilidades; las reglas financieras no conocen HTTP ni EF Core.

WebASP.NET Core MVC · Razor · ISender
AplicaciónMediatR · Handlers · DTOs · Interfaces
DominioEntidades · Invariantes · Excepciones
InfraestructuraEF Core · SQL Server · Identity · TimeProvider

Seguridad OWASP Top 10:2025

  • A01 Autorización denegar-por-defecto; filtro por UserId en cada consulta; tests IDOR.
  • A02–A03 Secretos fuera del repo; versiones centralizadas; MediatR 13.* aprobado.
  • A05 EF Core parametrizado; sin Html.Raw; validación en InputModel y dominio.
  • A07–A08 Contraseña ≥ 12; bloqueo 5 intentos; anti-forgery global; cookies seguras.
  • A09 Logs estructurados con ILogger; eventos de seguridad; sin PII.

LifeTrack 07 / 08

Próximos pasos

Mejoras pensadas para seguir simplificando mi día a día.

📱 PWA + Notificaciones

Instalable en móvil; recordatorios de presupuesto y resumen semanal vía Web Push.

🤖 Categorización asistida

Sugerencia de categoría por reglas de palabras clave (fallback) y opcionalmente LLM local; siempre con validación humana.

📊 Gráficos y exportación

Evolución temporal, comparativas año a año, exportar a Excel/PDF para revisión offline.

🏷️ Etiquetas y metas

Etiquetas libres en movimientos (ej. "viaje", "regalo") y metas de ahorro con seguimiento visual.

🔄 Importación bancaria (Open Banking)

Cuando el alcance lo permita: PSD2 / agregadores para sincronizar cuentas sin credenciales propias.

👥 Compartido familiar

Presupuestos y categorías compartidos con mi pareja; visibilidad selectiva y liquidación de gastos comunes.

Filosofía: Cada mejora nace de una fricción real en mi uso diario. LifeTrack no es un producto genérico; es mi herramienta, evolucionando conmigo.
